# Bitcoin Price Prediction Using Machine Learning

## Project Overview

This work focuses on developing machine learning classification models to predict Bitcoin buy and sell signals based on short-term and long-term price trends. Using historical Bitcoin trading data from Bitstamp, the project applies feature engineering and technical indicators to capture market trends and improve predictive performance.

The problem is formulated as a **binary classification task**, where:
- **1 (Buy):** Represents a buy signal.
- **0 (Sell):** Represents a sell signal.

## Methodology

- **Data Collection:** Historical Bitcoin price and trading data obtained from Bitstamp.
- **Feature Engineering:** Creation of technical indicators to capture price trends and market momentum.
- **Model Development:** Application of classification-based machine learning models to predict trading signals.
- **Model Evaluation:** Assessment of predictive performance using accuracy, precision, recall, and AUC.
- **Backtesting:** Simulation of trading strategies using historical data to evaluate profitability and risk.

## Objective

The main objective is to develop a data-driven Bitcoin trading strategy that generates reliable buy and sell signals while evaluating its potential profitability and associated risks before real-world implementation.

## Dataset

**Source:** [Bitcoin Historical Data – Kaggle](https://www.kaggle.com/datasets/mczielinski/bitcoin-historical-data)

**Exchange:** [Bitstamp](https://www.bitstamp.net/)
